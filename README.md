Giới Thiệu

Repository này được xây dựng nhằm thực hiện Phiếu Bài Tập 06 với chủ đề CSS Frameworks — Bootstrap 5 và Tailwind CSS.

Mục tiêu của bài tập là tìm hiểu, áp dụng và so sánh hai CSS Framework phổ biến hiện nay. Thông qua quá trình thực hành, sinh viên nắm được cách xây dựng giao diện hiện đại, tối ưu thời gian phát triển và nâng cao khả năng thiết kế Responsive Web.

---

Mục Tiêu Bài Tập

- Tìm hiểu kiến trúc và cách sử dụng Bootstrap 5.
- Tìm hiểu phương pháp Utility-First của Tailwind CSS.
- Xây dựng giao diện Web sử dụng CSS Framework.
- Thực hành Responsive Design trên nhiều kích thước màn hình.
- So sánh ưu điểm và hạn chế của Bootstrap 5 và Tailwind CSS.
